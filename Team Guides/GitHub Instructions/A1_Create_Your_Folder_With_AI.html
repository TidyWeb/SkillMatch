Guide A1

Add your folder with an AI assistant

Oana, John and Esmat: this process gets your own personal folder into the shared SkillMatch repository. Once it's merged, you appear in the Contributors list on the repository's front page, and the work counts on your own GitHub profile. An AI assistant in VS Code does the typing; you read and approve each step.

In short

  • You'll end up with a folder called Your-name's Folder next to Phil's Folder, containing a short README.md about you.
  • It goes up as a pull request, so it shows on your GitHub profile and nothing changes for anyone else until Phil merges it.
  • The AI is GitHub Copilot, built into VS Code. The free plan is enough. Allow 20 minutes the first time.

What happens, in order

Your work travels on its own branch, a separate lane, and only reaches main, the team's shared version, at the last step.

Before you start

  • You've accepted the invite to TidyWeb/SkillMatch. Esmat: look for the email from GitHub, or check github.com/notifications.
  • SkillMatch is cloned to your computer and opens in VS Code. If not, do step 02 of the "How we collaborate" guide first.
  • You know which email your GitHub account uses: on GitHub, click your picture → Settings → Emails. You'll need it in step 4.

Step 1Open SkillMatch in VS Code

File → Open Folder… and choose your SkillMatch folder. In the Explorer on the left you should see Phil's Folder, Research and README.md. If you don't, you've opened the wrong folder.

Step 2Connect the AI to your GitHub account

Copilot connects with your own GitHub sign-in. That means it can do exactly what your account is allowed to do in SkillMatch, and nothing more.

  1. Open the Chat view: the chat icon at the top of VS Code, or Ctrl+Alt+I (Mac: Cmd+Ctrl+I).
  2. If asked, choose Sign in with GitHub, using the same account that received Phil's invite. If offered a plan, pick Copilot Free.
  3. Below the chat box is a mode menu. Set it to Agent. In Agent mode the AI can create files and run commands, and it asks you before running each command.

VS Code moves its menus around now and then, so your wording may differ slightly. You're looking for three things: the Chat view, signed in with GitHub, set to Agent.

Step 3Pick your name and give the AI its instructions

Click your name, and the prompt fills itself in. Copy it, paste it into the Copilot chat, and press Enter.





The AI will ask you for two or three sentences about yourself for your README. The repository is public, so write what you'd put on LinkedIn: your background before the course and what you'd like to work on. No phone number, address or anything private.



Step 4Read before you approve


Before each command the AI explains what it's about to do, then waits for you to click Continue or Allow. The prompt tells it to stay inside these limits, but you are the final check.

Check the email. Git stamps every commit with a name and email, and GitHub only credits the commit to you if that email belongs to your account. The AI will show you the email before it commits. Compare it with GitHub → Settings → Emails. If it's wrong, tell the AI the right one and it will set it for SkillMatch only.



Step 5Open the pull request


If the AI could create the pull request, it gives you a link. If it couldn't, go to github.com/TidyWeb/SkillMatch. A yellow banner will say your branch had recent pushes: click Compare & pull request. Check the base is main, keep the title Add [your name]'s folder, and click Create pull request.


That's your part done. Phil reviews it and merges it. If he asks for a change, the pull request page shows his comment, and you can ask the AI to make the change on the same branch and push again.

If something unexpected happens, stop. Don't try fixes the AI suggests for a rejected push or a merge conflict. Take a screenshot and ask Phil. Nothing you've done can break the shared version.



Using a different AI


The prompt works with any AI coding assistant that can work in a GitHub repository. You give it the repository and the prompt in the same way. For example:


    
  
  • Claude Code (in a browser at claude.ai/code), if you have a paid Claude plan. You connect GitHub once, choose TidyWeb/SkillMatch, and paste the prompt. It works on its own branch and offers a Create PR button when it's done.
    • 
  
  • ChatGPT's Codex, if your ChatGPT plan includes it. It connects to GitHub in a similar way.
    • 



A plain chat window that can't reach your files or GitHub (ordinary ChatGPT or Claude chat) can't do this for you. It can only explain the steps. Use the route below instead.



No AI to hand? Do it in the browser


This takes about three minutes and gets you the same result.


    
  
  1. Open github.com/TidyWeb/SkillMatch and click Add file → Create new file.
    2. 
  
  2. In the name box, type Esmat's Folder/README.md, using your own name. Typing the / turns the first part into a folder.
    3. 
  
  3. Write two or three public-safe sentences about yourself.
    4. 
  
  4. Click Commit changes…, choose Create a new branch for this commit and start a pull request, then Propose changes and Create pull request.
    5.
