# Project visual language

Navy A is the house style used by every SkillMatch web page: the app, website, graduate guides, team guides and one-off pages.

## Folders

- `navy-a/` — the house-style rules, shared stylesheet and component kit.
- `github-profile-guide/` — the approved guide and the images it uses.
- `linkedin-profile-guide/` — the LinkedIn profile guide.
- `tailor-my-cv/` — the Tailor my CV page.
- `skillmatch-app/` — the app's Navy A styling notes.
- `skillmatch-da/` — SkillMatch data analysis pages.
