02 | Finding a real entry-level data job is a haystack¶

Question: How many distinct adverts survive the filters, which searches find the shown adverts, and how often might the data-role filter be wrong?

Data used: the prepared primary-advert, requirement, and history tables; the anchor run's funnel, search-term, and daily-change files; and the two filter-check samples.

Method

  • Show each funnel count from search appearances through primary adverts and the named filters.
  • Count same-source repeat sightings by source, then describe the title words and search-term yield.
  • Draw a seed-42 sample of 30 shown adverts and 30 adverts dropped as “not a data role”; label each from its title and requirement sentences.
  • Report Wilson 95% intervals for the two sample shares and show comparable weekly changes and listing duration.
  • Save each chart's source table, figure, the judgement labels, and the page findings.

The data-role pool follows the brief: primary adverts excluding only “not a data role” and “training course, not a job”. “Shown” means the database has no exclusion reason.

Wilson 95% intervals¶

The Wilson score interval is used for each yes-share because the samples are small. The share itself is the point estimate and effect-size measure. This is an interval estimate rather than a null-hypothesis test, so it has no p-value.

In [7]:
def wilson_interval(successes, sample_size, confidence=0.95):
    """Wilson score interval for a binomial share; returns proportions from 0 to 1."""
    if sample_size == 0:
        return (float("nan"), float("nan"))
    z = float(norm.ppf(1 - (1 - confidence) / 2))
    p = successes / sample_size
    denominator = 1 + z**2 / sample_size
    center = (p + z**2 / (2 * sample_size)) / denominator
    half_width = z * math.sqrt(p * (1 - p) / sample_size + z**2 / (4 * sample_size**2)) / denominator
    return center - half_width, center + half_width

What this shows¶

67 of 4,654 primary adverts were shown: about 1 in 69. The anchor funnel records 20,000 same-source repeat hits in 24,656 search appearances, and 6 of 48 search terms returned no shown matches. In the seed-42 review, 23 of 30 shown adverts and 1 of 30 adverts dropped as “not a data role” were judged to be data roles. The Wilson intervals are wide, so this sample is an accuracy check, not a precise estimate.

Limits¶

The anchor collection is marked incomplete, and Reed is marked partial. Search matches overlap, and same-source repeat hits count appearances rather than distinct adverts. The database separately marks 848 of 5,502 vacancy IDs non-primary. The filter labels say “Codex judgement, human check pending”; each has a manual reason and awaits human review; “data role” can be borderline. Wilson intervals describe these small samples and do not adjust for sampling without replacement. A listing missing at the next comparable collection is not confirmed filled. Incomplete source comparisons are left out, and the listed-day measure is only available for saved gone-listing rows.
