04 | Where AI appears in data-role adverts¶

Question: Which full-description adverts mention AI-family requirements, are those sentences concrete, and what does the advertised-pay comparison show?

Data used: the prepared primary advert and requirement tables, plus the sentence-by-sentence judgement file at data/labels/ai_sentences.csv.

Headline rule: sentence-family overlap is assigned to AI tools and generative AI. Machine-learning-only sentences are reported separately.

def wilson_interval(successes, total, z=1.96):
    if total <= 0:
        return (np.nan, np.nan)
    p = successes / total
    denom = 1 + z**2 / total
    centre = (p + z**2 / (2 * total)) / denom
    half = z * np.sqrt((p * (1 - p) / total) + (z**2 / (4 * total**2))) / denom
    return centre - half, centre + half

Scope and sentence-family rule¶

Requirement sentences are extracted from captured advert text. Search excerpts can hide most of an advert, so every sentence-based result below uses only the 378 full-description data-role adverts and their 5,853 requirement sentences.

The two families are mutually exclusive for headline counts. Machine learning contains sentences that mention machine learning or a clear ML abbreviation without AI-family wording. AI tools and generative AI contains AI, GenAI, LLM, ChatGPT, Copilot, prompt, Gemini, Claude, AI-assisted, agent or agentic wording. A sentence matching both is assigned to the AI family and counted in the overlap flag. Cryptography names ML-KEM and ML-DSA are excluded as non-machine-learning matches. One URL-only ai hit is excluded.

This audit finds 194 AI-family sentences, 35 ML-only sentences, and 21 sentences mentioning both families. The review’s earlier 188 AI-family / 28 ML-only counts reflect the direct AI terms and the full phrase “machine learning”; adding six agent-only sentences and seven clear ML-abbreviation-only sentences expands the families. Every included sentence has a role label, a specificity label, a reason and a method in the CSV. The labels say “Codex judgement, human check pending”.

Where AI appears¶

The chart uses the same 378 full-description adverts throughout. Group membership is mutually exclusive: shown, senior, outside the West Midlands, or other. Source family is Reed, company ATS boards (Greenhouse, Lever and Workable), or international remote boards (Remote OK and We Work Remotely). An advert counts once if it contains at least one AI-family requirement sentence.

The group and source shares use Wilson 95% intervals. The source-family chi-square tests whether AI-family mention rates differ across the three source families; it does not show that source type causes the difference.

def appearance_summary(frame, column, order, labels=None):
    rows = []
    for category in order:
        part = frame.loc[frame[column].eq(category)]
        n = int(part["vacancy_id"].nunique())
        mentioned = int(part.loc[part["ai_family_mentioned"], "vacancy_id"].nunique())
        low, high = wilson_interval(mentioned, n)
        rows.append({
            "category": category,
            "label": (labels or {}).get(category, category),
            "ai_family_adverts": mentioned,
            "full_description_adverts": n,
            "share": mentioned / n if n else np.nan,
            "wilson_95_low": low,
            "wilson_95_high": high,
        })
    return pd.DataFrame(rows)

Reading the prevalence result¶

AI-family mentions are rare in shown adverts and Reed listings, and much more common in senior and international remote-board adverts. The source-family test compares three recruitment-source groups; the Wilson intervals communicate uncertainty in each observed share. This is a description of this captured sample, not a representative estimate of every job advert.

The earlier 57 of 188 senior quick count includes machine-learning-only adverts. Under the requested AI-family headline rule, the count is 54 of 188. Adding the contextual agent-only sentences raises the remote-board count by one advert, to 52 of 116. The source and group tables preserve these definitions so the two counts are not mixed.

def salary_comparison(frame, flag, positive_label, negative_label, scope):
    positive = frame.loc[frame[flag], "annual_salary_midpoint_gbp"].astype(float)
    negative = frame.loc[~frame[flag], "annual_salary_midpoint_gbp"].astype(float)
    if len(positive) < 2 or len(negative) < 2:
        return {
            "scope": scope, "positive_label": positive_label, "negative_label": negative_label,
            "positive_n": int(len(positive)), "negative_n": int(len(negative)),
            "positive_median_gbp": float(positive.median()) if len(positive) else np.nan,
            "negative_median_gbp": float(negative.median()) if len(negative) else np.nan,
            "mannwhitney_u": np.nan, "mannwhitney_p": np.nan, "rank_biserial": np.nan,
        }
    test = mannwhitneyu(positive, negative, alternative="two-sided", method="asymptotic")

        "scope": scope, "positive_label": positive_label, "negative_label": negative_label,
        "positive_n": int(len(positive)), "negative_n": int(len(negative)),
        "positive_median_gbp": float(positive.median()), "negative_median_gbp": float(negative.median()),
        "mannwhitney_u": float(test.statistic), "mannwhitney_p": float(test.pvalue),
        "rank_biserial": float(2 * test.statistic / (len(positive) * len(negative)) - 1),
    }

def entry(identifier, value, label):
    if isinstance(value, (np.integer,)):
        value = int(value)
    elif isinstance(value, (np.floating, float)):
        value = float(value)
        if not np.isfinite(value):
            value = None
        else:
            if value != 0 and abs(value) < 0.0000005:
                value = float(value)
            else:
                value = round(value, 6)
    elif isinstance(value, (np.bool_,)):
        value = bool(value)
    return {"id": identifier, "value": value, "label": label, "notebook": "04_ai_gap.ipynb"}

What this shows¶

Limits¶

All sentence-based analyses use 378 full-description data-role adverts and 5,853 requirement sentences. Search excerpts are excluded because their requirement text is incomplete. Sentence counts are occurrences, while “Where AI appears” counts each advert once. The AI-family result includes contextual agent/agentic sentences and excludes URL-only false hits; some context may still be missed or misread. Machine-learning-only sentences are reported separately, and ML-KEM/ML-DSA cryptography references are excluded. Codex labelled every candidate sentence for role and specificity; a person has not checked those labels. Rory's spot-check found 3 of 18 sentences marked specific read as vague, so the 76.8% specificity share is an upper bound. Specificity is a judgement, and Wilson intervals on sentence shares treat occurrences as independent even though sentences cluster within adverts. Salary figures use stated salaries with usable annual midpoints; the sample is small and not representative, and salary differences do not establish an AI pay premium.
