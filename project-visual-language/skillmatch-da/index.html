What to do next

Learn Excel first, then SQL

Why this order? Excel is a familiar workplace tool; SQL builds on the filter, group and join logic you already know from pandas.

* coral asterisk: the course or its certificate costs money.

First

Excel

The same question as the SQL map, in Excel

“Show me the 10 best-paid entry-level data jobs in Birmingham.”

  1. Ctrl+T make the adverts a table
  2. Filter Town = Birmingham, Level = Entry
  3. Sort Salary, largest to smallest
  4. Read the top 10 rows
Or one formula (Excel 365) 
=TAKE(SORT(FILTER(Adverts,
  (Adverts[Town]="Birmingham") *
  (Adverts[Level]="Entry")
), 3, -1), 10)
When an advert says “advanced Excel”

It usually means lookups and PivotTables.

Most adverts ask for a level (“strong”, “advanced”) and never say which parts. When they do name features, it is VLOOKUP and pivot tables, together.

So learn these two first: XLOOKUP (or VLOOKUP on older Excel) to pull values from another table, and a PivotTable to summarise thousands of rows in a few clicks.

From 78 SkillMatch adverts that mention Excel, collected 30 October 2026. A guide, not a statistic.

SQL

SQL isn't one thing

SQL is a family of dialects, a bit like British and American English. The core is the same everywhere (SELECT, WHERE, JOIN, GROUP BY); the small print differs (LIMIT 10 in one, TOP 10 in another; dates; some function names).

The ones you'll meet: PostgreSQL (free, common in analytics teams); MySQL (free, behind many websites); Microsoft SQL Server, T-SQL (common in large UK organisations, alongside Excel and Power BI); SQLite (a small database in a single file; SkillMatch itself uses it); BigQuery, Snowflake, Databricks (cloud warehouses for very large data; Kaggle's course uses BigQuery).

Learn the core once, in any dialect; moving to another takes days, not months.

In the full-description data-role adverts, requests tagged SQL appear in 79 adverts; PostgreSQL in 16, MySQL in 3, SQL Server/T-SQL in 7, Google Cloud/BigQuery in 14, and Snowflake/Databricks in 17.

Source: the project's skill_explorer.csv, column data_role_full_adverts_asking. Skill tags can overlap.

How the pieces fit: one real question

“Show me the 10 best-paid entry-level data jobs in Birmingham.”

SELECT   title, employer, salary
FROM     adverts
WHERE    town = 'Birmingham'
  AND    level = 'Entry'
ORDER BY salary DESC
LIMIT    10;
You write it top to bottom. SQL runs it in this order:
  1. FROM find the adverts table
  2. WHERE keep Birmingham, entry level
  3. SELECT pick three columns
  4. ORDER BY highest salary first
  5. LIMIT stop after 10

Why it matters: WHERE runs before SELECT, so a column you rename in SELECT (with AS) doesn’t exist yet when WHERE runs. It’s one of the first errors beginners hit.
