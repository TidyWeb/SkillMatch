# Project development diary

Each SkillMatch team member's personal, honest reflection on the project. One file per person, in their own words.

## What to write about

- What you thought you were getting into at the start
- What you actually got into
- The difficulties you hit, and how you got through them (or didn't)
- Your ideas, and how they changed along the way
- How you used AI, and what it did and didn't do for you
- How the experience has affected you: skills, confidence, how you work, what's next

There's no word count and no set format. Bullet points, a timeline or plain prose are all fine. Honesty matters more than polish. Disagreement and frustration belong here too.

## How to add yours

1. Name the file `firstname-diary.md` (lower case, no spaces), for example `phil-diary.md`.
2. Put it in this folder, on a new branch from `main`.
3. Open a pull request titled `Add <name>'s project development diary`.
4. Change only your own file. Don't edit anyone else's.

If you used AI to help you remember or draft, say so at the top of your file. The reflections should still be yours.
