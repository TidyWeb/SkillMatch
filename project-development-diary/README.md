# Project development diary

Each SkillMatch team member's personal, honest reflection on the project: what you expected, what actually happened, what was hard, how your ideas changed, how you used AI, and what it has done for you. One file per person, in your own words.

## How we wrote them: an AI interviewer

Writing a reflection from a blank page is hard, and most people write less honestly when they're trying to sound good. So we used the same method as our CV Tailor biographer:

1. The AI asks you one question at a time and waits for each answer.
2. It follows up when an answer is vague, and asks for one concrete example.
3. It gathers what you say, in your words.
4. When it has enough, it sorts the wheat from the chaff and writes a draft in the first person, one heading per section.
5. You edit the draft, save it as a Markdown file, and add it here through your own pull request.

The AI draws the story out of you. The words, the judgement and the final edit are yours.

**To start:** copy your prompt from [diary-interview-prompts.md](diary-interview-prompts.md) and paste it into the AI you use (Claude, ChatGPT, Copilot, Gemini or similar). That file also has the prompt for each team member and the rules we set for them.

## How to add yours

1. Name the file `firstname-diary.md` (lower case, no spaces), for example `phil-diary.md`.
2. Put it in this folder, on a new branch from `main`.
3. Open a pull request titled `Add <name>'s project development diary`.
4. Change only your own file. Don't edit anyone else's.

If AI helped you remember or draft, say so on the first line of your file, as the prompt asks. The reflections should still be yours.

## What to write about

- What you thought you were getting into at the start
- What you actually got into
- The difficulties you hit, and how you got through them (or didn't)
- Your ideas, and how they changed along the way
- How you used AI, and what it did and didn't do for you
- How the experience has affected you: skills, confidence, how you work, what's next

There's no word count and no set format. Honesty matters more than polish. Disagreement and frustration belong here too.
