The [28 October board picture](Board_Picture_20261028_1750.png) gives a human-readable view from 17:50 UTC. Its status counts cover issues; the JSON snapshot eleven minutes later also includes pull requests, so the totals differ.

The 31 October JSON was captured before the later evening board review. Treat it as a checkpoint, not the final board state for that day.

The files retain the captured project fields and item metadata. They are useful for seeing what was on the board and how its recorded fields changed. They do not include the full discussion on each issue and do not establish that work was finished; use merged pull requests and the project history for that.

For future additions, keep dated snapshots as separate files. Do not replace an earlier capture with a newer one.
