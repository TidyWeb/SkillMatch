# SK's Folder

Tailor my CV helps a Code Institute graduate rewrite their CV for a job SkillMatch found, using their own free Claude desktop app. Phil and SK are building and testing it today, Wednesday 28 October.

This folder holds the context, plan, pictures and trial files for that work.

## Start here

1. **Give your AI the project context.** Load [`SK_Context_Tailor_My_CV.md`](SK_Context_Tailor_My_CV.md) into Copilot, DeepSeek or another AI. It explains the project, its agreed rules and how Phil and SK plan to work together.

2. **Read the plan overview.** [`SK_Tailor_My_CV_Plan_20261027.md`](SK_Tailor_My_CV_Plan_20261027.md) explains the design. Raise questions or changes with Phil before relying on anything that may have changed.

3. **Look at the workflow.** [`SK_Tailor_My_CV_Workflow.png`](SK_Tailor_My_CV_Workflow.png) shows how the SkillMatch App, the Tailor my CV page and the user's computer fit together, and why it's built this way.

4. **See what the SkillMatch Skill will do.** [`SK_SkillMatch_Skill_Overview.png`](SK_SkillMatch_Skill_Overview.png) shows the one-off set-up and the skill's three jobs: Update my CV, Biography and Tailor. This is the design we're building today; the skill doesn't exist yet.

5. **Run the Claude trial.** Follow [`SK_Free_Claude_Desktop_Trial_Run.md`](SK_Free_Claude_Desktop_Trial_Run.md) on a free Claude account. Use the made-up CV in [`SK_test_cv.docx`](SK_test_cv.docx), not a real CV.

6. **Upload the test skill as provided.** Use [`SK_skillmatch-trial.zip`](SK_skillmatch-trial.zip) for the skill test. Upload the zip file as it is; don't unzip it.

7. **Share the results.** Fill in the report block at the end of the trial file and post it in Discord, with any useful screenshots. The results decide how parts of the skill work.

8. **Agree the work and swap reviews.** The proposed split: SK builds the Tailor my CV page, Phil builds the SkillMatch Skill. Confirm it with Phil. Phil will share the job brief format (the text the page copies for Claude) and short steps for opening pull requests on GitHub.

## Keep personal information private

Keep real CVs and biographies on your own computer. Use made-up examples for anything shared in the repository, which is public.
