Step 1 of 4

Review a pull request

Read someone's proposed change, comment on it, and either approve it or ask for changes. You can't review your own.

  1. Open it Repository → Pull requests → click the one you've been asked to review.
  2. Read the changes Files changed tab. To comment on a line, hover over it and click +.
  3. Give your verdict Review changes (top right) → Comment, Approve or Request changes → Submit review.
Check thatRequest changes if
It does what its card saysIt changes files it has no reason to touch
