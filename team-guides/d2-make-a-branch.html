Make a branch for your card

Give each task its own lane, named after its card on the board. Nothing you do there changes anyone else's work.

  1. Find your card's number On the project board, open your card. The number is next to its title, e.g. #24.
  2. Create the branch Click the branch name in the bottom-left → Create new branch… → type the number and a few words, with hyphens: 
    24-interface-feedback
  3. Check you're on it The bottom-left now shows your branch name. Work only here, never on main. GitHub won't accept changes pushed straight to main anyway.
Prefer your AI assistant to do it? Paste this into whichever one you use:
Create and switch to a new branch called 24-interface-feedback, starting from an up-to-date main.

Done when: the bottom-left shows your new branch name.
