Protect main

Why nobody can push straight to the shared version, and how the rule is set. For the repository owner.

The rule on main (ruleset "Protect main")

  • Pull request required: every change goes through a pull request, Phil's included. No exceptions.
  • Approvals needed: 0 for now, so work isn't stuck waiting while people are busy. It can be raised to 1 for the hackathon week.
  • Squash merges only; no force pushes; main can't be deleted.
  • Merged branches delete themselves.
  1. See it Repository → Settings → Rules → Rulesets → Protect main.
  2. Require a reviewer (when the team agrees) Under Require a pull request before merging, set Required approvals to 1 → Save changes.

Done when: a direct push to main is rejected, and changes arrive only through merged pull requests.
