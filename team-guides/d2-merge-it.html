Step 2 of 4

Merge it

Add an approved pull request to the shared version. For now Phil merges code; who merges docs is decided on Monday.

  1. Check it's ready On the Conversation tab: every comment resolved, and no message saying the branch has conflicts (if it has, see D3).
  2. Squash and merge Click Squash and merge, tidy the message so it says what changed, then Confirm squash and merge. The whole pull request becomes one clean commit on main.
  3. Let GitHub tidy up The branch is deleted automatically, and any card named with Closes #n moves to Done.

Done when: the pull request says Merged. For pages on the hub, check the live page a couple of minutes later.
