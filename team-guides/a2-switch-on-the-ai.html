Switch on the AI

Turn on GitHub Copilot in VS Code and set it to Agent, so it can do the typing. The free plan is enough. About 5 minutes.

  1. Sign in Hover over the Copilot icon in the bottom status bar → Use AI Features → sign in with the GitHub account Phil invited. With no subscription you get Copilot Free.
  2. Open a chat set to Agent Open the Chat view, start a new chat with +, and choose Agent in the picker under the message box. (Ask only answers questions; Plan doesn't act.)

Already use Claude or Codex in VS Code? Either works with the same prompt.

Done when: you have an empty chat set to Agent.
