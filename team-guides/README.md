## Viewing the Code Institute resource index

Open the [Code Institute Resources Visual Index](https://tidyweb.github.io/SkillMatch/Resources/Code_Institute_Resource_Index.html) to follow the links to the LMS. You need an internet connection and your own Code Institute sign-in. The PDF is a printable list of resource names and links; it does not contain the course materials.

## Viewing the HTML plan

In **Project documents** above, select **View the project plan as a web page** to open the rendered plan published with GitHub Pages.

If you open `Job_Search_App_Plan.html` from the repository's **Code** file list and see HTML tags, you are viewing the source file. Return here and use the webpage link to read the formatted plan.

GitHub Pages displays these static pages; it does not run the Flask application itself.

## Status (as of 30 October 2026)

A working prototype exists: a Flask web app that compares a graduate's skills with West Midlands vacancies. Its code is in [`skillmatch-app/`](../skillmatch-app/). **[Try it in your browser](https://codespaces.new/TidyWeb/SkillMatch)** with GitHub Codespaces: nothing to install. The prototype will eventually show live jobs. For now, Codespaces runs a saved copy of a live collection; if that copy is unavailable, it uses sample adverts. We are now designing the interface; the prototype designs will appear on the [team hub](index.html) as they are ready. Salary policy and the travel-routing provider remain open team decisions. Keep missing pay unknown and do not estimate it.
