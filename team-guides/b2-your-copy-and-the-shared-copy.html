B2 · GITHUB BASICS

Your copy and the shared copy

A file can be on GitHub, in your linked clone folder, or somewhere else on your computer. Knowing which one you're looking at explains almost every “why isn't my file on GitHub?” moment.

Before this guide: you've done A1, so SkillMatch is already cloned on your computer. This guide explains what that gave you.

Find out where your clone is

  1. Open the clone in VS Code File → Open Recent → SkillMatch. The Explorer on the left now shows the clone's contents.
  2. Reveal it on your computer Right-click any file in the Explorer → Reveal in File Explorer (Windows), Reveal in Finder (Mac) or Open Containing Folder (Linux). The window that opens is your clone. Remember where it is.
  3. Read the bottom-left corner It shows the branch you're on, such as main. Every guide that says "check the bottom-left" means this.

Prove it to yourself (2 minutes)

This test shows what GitHub can and can't see. It changes nothing on GitHub, as long as you do the last step.

  1. Make a file outside the clone In your Downloads folder, create a text file called test.txt. Look at VS Code's Source Control. Nothing appears, because VS Code and Git don't know the file exists.
  2. Move it into the clone Drag test.txt into the clone folder you revealed above. Source Control now lists test.txt with a U beside it. U means untracked: Git can see the file but isn't keeping track of it yet.
  3. Delete it Delete test.txt from the clone folder. Source Control goes quiet again. Don't commit it.

Where is my change right now?

"It's not on GitHub!" almost always means the change hasn't reached that step yet. Each action moves it one place further.

You have…Your change is…Who can see it
Saved the fileIn your clone folder, not yet committedOnly you
Committed itA checkpoint on your branch, still on your computerOnly you
Pushed (Publish Branch / Sync Changes)On GitHub, on your branchAnyone who opens the repository, but it isn't in main yet
Had the pull request mergedIn main on GitHubEveryone, once they pull
Pulled (a teammate does this)In their clone folder tooThem

Two words you'll keep seeing

origin is the short name your clone uses for the GitHub repository it came from. main is the team's agreed shared branch. That's all either word means.

If a file isn't inside the clone folder, GitHub can't see it. If it's in the clone but you haven't committed and pushed it, only you can see it.

Done when: you can point to your clone folder, and explain why a screenshot sitting in Downloads isn't on GitHub.
