Step 1 of 5

Start from the latest

Before every task, bring your copy up to date with the team's shared version. One minute.

Before this guide: SkillMatch must already be on your computer. That means you have made a projects folder and cloned the repository into it, which is A1. If you haven't, do A1 first. This guide won't work without it.

  1. Open SkillMatch in VS Code File → Open Recent → SkillMatch. If it isn't in the list, choose File → Open Folder instead and pick the SkillMatch folder inside your projects folder.
  2. Switch to main Click the branch name in the bottom-left corner and choose main.
  3. Pull Source Control → … → Pull. This downloads everything teammates have had merged.

Prefer your AI assistant to do it? Paste this into whichever one you use:

Switch this repository to main and pull the latest changes. Tell me if anything is uncommitted first, and don't discard it.

Done when: the bottom-left says main and Pull reports nothing new, or has finished downloading.
