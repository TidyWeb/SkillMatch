SKILLMATCH · TEAM TEST

Test Tailor my CV

Try the set-up, biography and tailoring flow. Allow about 45 minutes.

Why

We need to know where real people get stuck. Be honest; confusing bits are the most useful thing you can report.

Before you start

  • Allow about 45 minutes.
  • Use a Windows, Mac or Linux computer, not a phone.
  • A free Claude account is best.
  • Use your own CV, or a made-up one if you’d rather.
  • The SkillMatch App link is in Discord. It isn’t public yet.
If you used an earlier SkillMatch Skill, remove it in Customize > Skills first.
Test 1

Set up (about 20 min)

Follow Set up once on the Tailor my CV page, steps 1 to 5, exactly as written.

  • How many minutes did it take?
  • Did you get stuck at any step? Note the step or write “none”.
  • Did Desktop Commander need a second install? Note yes or no.
Test 2

Biography (about 10 min)

Start a new chat in the Claude desktop app. Type run SkillMatch and choose biography. Do one job only.

Check: Did it ask one question at a time? Did it move on once a story was complete? Did biography.md appear in your SkillMatch Folder?

In the same chat, type add to my biography: <something you just remembered>. Check it was added without restarting the interview.

Test 3

Tailor (about 15 min)

In the SkillMatch App, find a job, expand the card and press Tailor my CV.

On the page, press Copy for Claude. Paste it into a new chat in the Claude desktop app and send it.

Check: Did it give a fit check first? Did it show what matches and what’s missing? Did it ask whether you want suggestions or a full CV? Were files saved in Tailored CVs?

Also try Open in Claude desktop once. Did it open the app with the text typed in?
