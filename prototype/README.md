# SkillMatch – Testing Version (Oana)

## Overview

This branch contains an earlier version of the SkillMatch application, developed to test and evaluate changes to its job-matching functionality.

Unlike the original prototype, which uses synthetic job adverts for demonstration purposes, this version has been tested using real job advertisements from Reed.

## Open in GitHub Codespaces

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/TidyWeb/SkillMatch)

Click the button, then **Create codespace**, and wait for the environment to finish setting up.

When the terminal displays that the application is running at http://127.0.0.1:5000, hold **Ctrl** (Windows/Linux) or **Cmd** (Mac) and click the address to open SkillMatch in a new browser tab.

## Testing with real job adverts

The application retrieves and displays real Reed job listings, including job titles, employer information and links to the original advertisements.

Users can follow the links to view the corresponding listings on Reed.

Access to Reed data depends on the relevant API configuration and usage permissions. The presence of real job listings in the testing version does not imply permission to redistribute Reed's advert content.


## Development and testing

This branch provides a separate environment for experimenting with improvements to the application without changing the original prototype.

The work includes:

* Testing the application with real Reed job advertisements.

* Investigating and refining the job-matching functionality.

* Evaluating changes to the matching logic.

* Supporting further development and testing of the application.

## Original prototype

The original SkillMatch prototype remains available in the main project. Its documentation and instructions for running it with synthetic adverts or an individual Reed API key can be found in the main repository README.
