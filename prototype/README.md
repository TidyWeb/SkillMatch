# SkillMatch prototypes

## Try the working prototype (no installing)

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/TidyWeb/SkillMatch)

Click the button, then **Create codespace**. After a few minutes the first time, SkillMatch opens in a new tab. Step-by-step help: [Guide B1, Try the prototype](https://tidyweb.github.io/SkillMatch/team-guides/b1-try-the-prototype.html).

**The adverts are made up.** It runs on 119 synthetic adverts from fictional employers, because we don't yet have Reed's permission to share real adverts. To see real West Midlands jobs, use your own free Reed key: [Guide B2, See real jobs with your own Reed key](https://tidyweb.github.io/SkillMatch/team-guides/b2-real-jobs-with-your-own-reed-key.html).

## What's in here
