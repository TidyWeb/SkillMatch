Tier B: checked by hand

What the providers' documentation says

We read each provider's documentation and terms before connecting to it. In plain English:

  • Reed publishes its search and job-details API with a free key. It states no rate limit, attribution rule or storage terms, so we stay cautious: about one request a second, a hard cap per run, responses cached for a day, and no copying of whole adverts. Reed's website terms forbid copying for commercial use; SkillMatch is a non-commercial education project. Before any public launch the team should ask Reed to confirm this use is fine.
  • Greenhouse, Lever and Workable document public, read-only routes to each employer's published jobs. There's no search across employers, so we list the employers we follow.
  • We Work Remotely offers its RSS feed for anyone to use, asking that links go back to it. Remote OK's feed asks users to link back to the job on Remote OK, name it as the source and not use its logo. Its salary figures may be estimates, so we don't show them.
  • CV-Library's affiliate terms page refused our automated check, so the conditions above come from the team's notes and still need confirming against the page itself.
  • Adzuna is not used: its free key is for evaluation only.
  • Postcodes come from postcodes.io (no key). Contains OS data © Crown copyright and database right; contains Royal Mail data © Royal Mail copyright and database right; source: Office for National Statistics.
  • Map tiles © OpenStreetMap contributors.
