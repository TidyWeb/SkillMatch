# SkillMatch prototype

The live app is at [SkillMatch](https://skillmatch-926015010605.europe-west2.run.app). This folder holds its code.

## Just opened this in Codespaces?

You don't need to do anything here. Wait for the terminal at the bottom to finish setting up (a few minutes the first time). When it says:

    Running on http://127.0.0.1:5000

hold **Ctrl** (Windows or Linux) or **Cmd** (Mac) and **click that address**. SkillMatch opens in a new tab. Ignore the other addresses it lists.

## Run it yourself in Codespaces (for working on the code)

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/TidyWeb/SkillMatch)

Click the button, then **Create codespace**. Step-by-step help: [Guide C1, Try the prototype (older guide, archived)](https://tidyweb.github.io/SkillMatch/team-guides/archive/2026-10-30_before_navy_a/c1-try-the-prototype.html).

**The adverts are made up.** In Codespaces it runs on 119 synthetic adverts from fictional employers, because we don't yet have Reed's permission to share real adverts. To see real West Midlands jobs, use your own free Reed key: [Guide C2 (older guide, archived)](https://tidyweb.github.io/SkillMatch/team-guides/archive/2026-10-30_before_navy_a/c2-real-jobs-with-your-own-reed-key.html). The live app uses real adverts collected from six job sites.
